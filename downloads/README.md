# DEADBLOCK 0.9 pour Windows

Téléchargez **DEADBLOCK-Windows.zip** avec le bouton de téléchargement de GitHub.

1. Fermez la fenêtre JOUER de l’ancienne version.
2. Clic droit sur le nouveau ZIP : **Extraire tout**.
3. Ouvrez le dossier extrait, puis double-cliquez sur **JOUER.bat**. Gardez sa fenêtre ouverte.
4. Ouvrez **Campagne**, choisissez la première mission puis **Déployer l’escouade**.

La version 0.9 ajoute des modèles 3D Kenney téléchargés depuis le dépôt officiel Starter Kit Racing : pick-up en deux couleurs dans les trois cartes, motos et campement sur leurs abords. Leurs teintes sont atténuées et les pick-up remplacent les anciennes voitures. Les modèles, textures, sources et crédits CC0 sont inclus dans le ZIP : aucun téléchargement d’asset pendant une partie.

Le bouton en forme d’engrenage du refuge ouvre les modes Automatique, Fluidité et Qualité. Les réglages sont aussi accessibles depuis l’aide en partie et sont mémorisés dans le navigateur. La partie continue lorsque cette fenêtre est ouverte.

Cette version comprend 9 missions avec objectifs et extraction, 3 cartes distinctes, 12 armes, 14 contrats, une boutique, la fabrication, 3 boss animés et une mini-carte. Les missions se débloquent dans l’ordre et la progression est sauvegardée. Maintenez E près des objectifs pour interagir.

Les armes utilisent deux modèles de base Kenney sous licence CC0, adaptés en douze variantes avec canons, stocks, chargeurs, réservoirs et effets distincts. Les boss utilisent les modèles Quaternius. Les nouveaux décors viennent de https://github.com/KenneyNL/Starter-Kit-Racing (modèles et textures CC0). Tous les modèles et textures sont inclus, avec leurs sources et crédits dans le dossier Licences.

Windows 10/11 x64 ; moteur inclus, aucune installation de Node.js nécessaire. Utilisez le même navigateur pour retrouver votre sauvegarde. Coopération jusqu’à 4 joueurs sur le même réseau local ; pas de serveur Internet public fourni.

Validation : 32 tests de logique/serveur et 5 scénarios navigateur ciblés. Archive extraite vérifiée sous Linux/Chromium ; lancement natif Windows à confirmer sur Windows.
