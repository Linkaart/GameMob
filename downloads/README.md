# DEADBLOCK 0.4 pour Windows

Téléchargez **DEADBLOCK-Windows.zip** avec le bouton de téléchargement de GitHub.

1. Fermez la fenêtre JOUER de l’ancienne version si elle est ouverte.
2. Clic droit sur le nouveau ZIP : **Extraire tout**.
3. Ouvrez le dossier extrait puis double-cliquez sur **JOUER.bat**. Gardez sa fenêtre ouverte.

Les trois boss utilisent maintenant des modèles animés Quaternius, adaptés avec armures, masques, poches toxiques et bobines électriques. Ouvrez **Bestiaire → Examiner en 3D** pour les voir, puis **Préparer la chasse** pour les affronter. Marche, course en rage, coups de mêlée et lueurs sont animés. La barre de vie a été déplacée pour dégager leur silhouette.

Les modèles et leurs textures sont inclus : aucun téléchargement supplémentaire pendant le jeu. Sources et crédits dans `app/dist/assets/bosses/CREDITS.txt` et `Licences/Quaternius-Bosses-CREDITS.txt`.

Windows 10/11 x64 ; moteur inclus. Les sauvegardes utilisent le même emplacement et la même adresse que les versions précédentes : utilisez le même navigateur. Coopération sur le même réseau local ; pas de serveur Internet public fourni.

Validation : 23 tests de logique/serveur et quatre scénarios navigateur ciblés (trois boss, inspection des armes, chasse et refuge mobile). Contrôle de l’archive extraite sous Linux/Chromium ; lancement natif Windows à vérifier sur Windows.
