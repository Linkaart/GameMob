# DEADBLOCK 0.7 pour Windows

Téléchargez **DEADBLOCK-Windows.zip** avec le bouton de téléchargement de GitHub.

1. Fermez la fenêtre JOUER de l’ancienne version.
2. Clic droit sur le nouveau ZIP : **Extraire tout**.
3. Ouvrez le dossier extrait, puis double-cliquez sur **JOUER.bat**. Gardez sa fenêtre ouverte.
4. Ouvrez **Campagne**, choisissez la première mission puis **Déployer l’escouade**.

La mise à jour graphique ajoute des reflets d’environnement sur les armes et surfaces humides, des micro-rayures sur les accessoires métalliques, une lampe du survivant qui suit sa visée, des halos de lampadaires et des flammes plus douces. Le rendu conserve les proportions stylisées inspirées de Call of Mini Zombies. Les textures sont créées localement dans le projet. La résolution 3D et les ombres s’adaptent automatiquement aux performances ; le texte et les commandes restent nets.

Cette version comprend 9 missions avec objectifs et extraction, 3 cartes distinctes, 12 armes, 14 contrats, une boutique, la fabrication, 3 boss animés et une mini-carte. Les missions se débloquent dans l’ordre et la progression est sauvegardée. Maintenez E près des objectifs pour interagir.

Les armes utilisent deux modèles de base Kenney sous licence CC0, adaptés en douze variantes avec canons, stocks, chargeurs, réservoirs et effets distincts. Les boss utilisent les modèles Quaternius. Tous les modèles et textures sont inclus, avec leurs sources et crédits dans le dossier Licences.

Windows 10/11 x64 ; moteur inclus, aucune installation de Node.js nécessaire. Utilisez le même navigateur pour retrouver votre sauvegarde. Coopération jusqu’à 4 joueurs sur le même réseau local ; pas de serveur Internet public fourni.

Validation : 30 tests de logique/serveur et 8 scénarios navigateur ciblés. Archive extraite vérifiée sous Linux/Chromium ; lancement natif Windows à confirmer sur Windows.
