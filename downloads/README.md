# DEADBLOCK 0.3 pour Windows

Téléchargez **DEADBLOCK-Windows.zip** avec le bouton de téléchargement de GitHub.

1. Fermez la fenêtre JOUER d’une ancienne version si elle est ouverte.
2. Clic droit sur le ZIP : **Extraire tout**.
3. Ouvrez le dossier extrait puis double-cliquez sur **JOUER.bat**. Gardez sa fenêtre ouverte.

Le navigateur ouvre le refuge. Dans Arsenal, cliquez sur **Examiner en 3D** pour tourner les huit armes et les cinq caisses originales. Le moteur est inclus ; aucune installation supplémentaire. Windows 10/11 x64.

La sauvegarde permanente utilise le même emplacement et la même adresse locale que la version 0.2 : utilisez le même navigateur pour retrouver votre profil. Multijoueur sur le même réseau local ; aucun serveur Internet public n’est fourni.

Les images et statistiques demandées sur le wiki Fandom ne sont pas encore importées : le réseau de développement refuse actuellement ce domaine. Les visuels sont originaux et les statistiques restent celles du prototype.

23 tests de logique/serveur et huit scénarios navigateur validés. L’archive extraite a également été testée dans Chromium sous Linux. Le double-clic natif Windows reste à vérifier sur Windows.
