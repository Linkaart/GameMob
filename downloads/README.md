# DEADBLOCK pour Windows

Téléchargez `DEADBLOCK-Windows.zip` dans ce dossier avec le bouton de téléchargement de GitHub.

1. Clic droit sur le ZIP : **Extraire tout**.
2. Ouvrez le dossier `DEADBLOCK-Windows` extrait.
3. Double-cliquez sur **JOUER.bat** et gardez la fenêtre ouverte.

Le jeu doit s’ouvrir dans le navigateur. Le runtime Node.js est fourni : aucune installation supplémentaire. Windows 10/11 x64. Multijoueur sur le même réseau local ; aucun serveur Internet public n’est fourni.

L’archive et son démarrage ont été vérifiés dans Chromium sous Linux. Le double-clic et l’ouverture du navigateur sous Windows restent à valider sur Windows.
